# Data

One dataset in v0: a synthetic return series. Nothing here is market data.

| Item | Value |
|---|---|
| File | `data/series/v1.json` (generated by `bun run gen:series`; **not yet generated**) |
| Generator | `regime-switching-v1` in `packages/core/src/series.ts` |
| Seed | `20261017` |
| Length N | 192 returns, `int16` basis points, clipped to ±300 |
| Roles | dev earn range `[6, 128)`, confirm `[128, 160)`, sealed `[160, 192)` |
| Regimes | segments of 20 to 40 steps drawn from: trend (drift ±6 to ±14 bp plus noise σ 14), momentum (AR(1) φ = +0.55), mean reversion (φ = −0.55), chop (white noise σ 22) |
| Identity | the on-chain `epoch` hash over (spec version, cost, role boundaries, returns); the file also records the SHA-256 of the returns array |
| Golden vectors | `data/golden.json`: 200 specs with expected scores for all three roles from the TypeScript mirror (**not yet generated**) |

## Why synthetic

Kuru's testnet book is unverified and Jev Trader's market is mainnet; we need a deterministic, shared, auditable series today ([decision 0006](decisions/0006-synthetic-series-first.md)).
The regime mix is a design choice and could make a family of strategies look good; the seed and generator are therefore fixed and public, and the sealed score is shown next to dev.

## Roles and looks

| Role | Used for | Looks |
|---|---|---|
| dev | search (every candidate) | unlimited |
| confirm | choosing the champion among the dev top-k | one recorded look per candidate |
| sealed | the single claim | one recorded look per candidate, by its proposer; the data is public on-chain (see [FAQ](faq.md)) |

Decisions use lags of up to 5 steps before the earn range, so the first decisions of confirm and sealed use returns from the previous role as *inputs* (not as earned returns). This is ordinary walk-forward; it means roles are not independent windows of data, only of *earned* returns.

## Limits

- Not real; says nothing about any market.
- Short (32 earned steps in each of confirm and sealed): single sealed scores are noisy.
- Changing seed, length, boundaries, cost or spec version changes the epoch.
